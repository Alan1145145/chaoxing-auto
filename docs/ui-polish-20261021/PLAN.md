# UI 补齐与交互改造

用户反馈：多个页面仍保留旧布局，缺少动画；顶部标题改为 AI智能学习。

范围清单：
- 品牌：原生窗口、网页标题、标题栏、工作区标识、导航后的窗口名。
- 页面：工作台、豆包、本地题库、浏览器、脚本、应用中心、监控、模型接入、设置、简洁模式、书签与内嵌浏览器。
- 子面板：浏览器配置、初始化步骤、搜索/编辑弹窗、下拉菜单、空状态。
- 动效：路由淡入滑动、导航滑块、卡片分批入场和悬停、按钮按压/波纹、设置切换、聊天消息入场；尊重 prefers-reduced-motion。

采用现有 Vue Transition、CSS 动画、Arco 控件，不引入新的动画依赖。
保留原运行、脚本、账号与存储逻辑；卡片浏览器视图旁保留带拖拽功能的列表视图。

改动前源文件已复制至 before/。当前目录无 Git，未创建 Git checkpoint。
验证待执行：TypeScript、生产构建、逐页视觉与交互检查、新 Windows 目录包。
