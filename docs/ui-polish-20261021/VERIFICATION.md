## 问题记录与修复边界

- BF-UI-01：旧 common.css/common.less 在弹出菜单及树节点上设置 animation:none!important / transition:none!important。已去掉强制禁用，恢复 Arco 默认动效；motion.css 为用户的减少动画偏好保留覆盖。
- BF-UI-02：课程配置位于 closed ShadowRoot，全局 CSS 无法进入；已有颜色还硬编码为蓝/白。现在按原渲染顺序追加 ocs-config-theme.css，保留配置生成与保存逻辑。
- BF-UI-03：独立根路由的下拉菜单根组件不适合套 out-in Transition，会导致简洁模式切换后空白。已移除根级过渡，保留 KeepAlive 和子页面动画，并验证模式往返。
- BF-UI-04：卡片动画 fill-mode:both 会在结束后固定 transform，覆盖悬停位移。入场动画改为 backwards，入场后交由悬停样式控制。
- BF-UI-05：旧深色链接规则强制蓝色，导致新导航滑块文字不清；已去掉强制覆盖，并补齐深色 Arco 颜色变量。
