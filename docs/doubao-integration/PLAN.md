# 豆包与 Dew 界面改造

范围：内置本地网关、扫码/官方网页/Cookie 登录、现有题库答题接入、助手页与全局界面。

来源：用户指定的本地 Doubao2api-main；原始说明保存在 packages/app/vendor/doubao/UPSTREAM.md。
复用 Python Flask 网关与现有 Vue/Arco/Electron，不新增另一套 UI 框架。

- M-1 网关：独立子进程，随机本地端口和鉴权密钥，退出时回收。
- M-2 登录：凭据仅主进程保存，使用现有加密函数，不复制原项目 .env 或账号。
- M-3 答题：内置 provider 接入现有题库流程；普通聊天与自动答题分开。
- M-4 界面：参考 Dew 的灰白卡片、橄榄绿主卡、柔黄色点缀，保留原功能入口。
- E-1 验证：TypeScript、前端构建、原网关离线测试、集成本地测试与界面检查。
