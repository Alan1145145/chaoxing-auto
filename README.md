# 超星自动机

超星自动机是一个 Windows 桌面端学习助手，基于开源项目 [OCS Desktop](https://github.com/ocsjs/ocs-desktop) 和 [OCSJS](https://github.com/ocsjs/ocsjs) 修改而来。

- 作者：alan34
- 原作者：enncy / ocsjs 团队
- 当前版本：1.0.5

## 相对原版的主要改动

- 更名为「超星自动机」，新增「关于软件」页面
- 接入豆包 AI 答题（豆包 App 扫码登录，内置本地网关）
- 新增「接入千问」预设（阿里云百炼 OpenAI 兼容接口）
- 模型接入支持一键获取模型、保存前测试连接；保存和切换模型后自动接入 OCS JS，已打开的课程页和 iframe 自动同步
- 公告改为本地使用教程；更新只连接本项目 GitHub，提示新版本后点击即可自动下载、校验、保存数据并安装重启
- 界面细节调整

## 下载

到 [最新 Release](https://github.com/Alan1145145/chaoxing-auto/releases/latest) 下载 Windows x64 安装包，支持 Windows 10/11。安装完成后，从桌面或开始菜单启动。

1.0.4 及以前的用户需最后手动覆盖安装一次 1.0.5 或更新版本，无需先卸载。之后软件启动后和每 4 小时会检查正式版本；点击「立即更新」后自动完成下载、校验、保存与安装重启。也可在「帮助 → 检查更新」手动检查。可取消下载，失败后可重试；更新保留设置、题库、模型密钥和浏览器登录数据。

使用模型时，在「模型接入」中填写服务地址和 API Key，点击「一键获取模型」选择模型，再保存即可。服务商未提供模型列表时，可以手动填写模型 ID。
